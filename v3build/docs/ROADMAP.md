# Production roadmap

## Phase 1 — foundation
- Tenant auth/RBAC
- PostgreSQL
- Redis + queue
- encrypted provider secrets
- migrations
- observability

## Phase 2 — real data
- approved discovery APIs
- enrichment/verification providers
- evidence normalization
- deduplication
- source provenance

## Phase 3 — real outreach
- Gmail OAuth
- Microsoft 365 OAuth
- Resend/SMTP
- Twilio/Exotel/SIP
- provider webhooks
- idempotent event processing
- rate limits

## Phase 4 — AI
- LLM gateway
- structured tool calling
- research/personalization/reply agents
- conversation memory
- qualification policies
- human approval mode

## Phase 5 — calendar/CRM
- Calendly webhooks
- built-in CRM
- HubSpot/Salesforce/Pipedrive adapters
- meeting notifications

## Phase 6 — scale
- browser/dashboard frontend
- billing
- usage limits
- analytics
- A/B testing
- campaign optimization
- regional compliance policies
